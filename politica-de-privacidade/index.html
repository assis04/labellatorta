Política de privacidade

Este site foi feito para coletar o mínimo possível. Aqui explicamos, sem juridiquês, o que acontece com os seus dados quando você o visita.

Em resumo

  • Este site não usa cookies.
  • Nenhum formulário envia dados para este site: a encomenda abre o WhatsApp no seu aparelho, e você decide se envia.
  • Não usamos ferramenta de estatísticas de visita.
  • O mapa do Google só carrega se você clicar em “Carregar mapa”.
  • Dúvidas ou pedidos sobre seus dados: labellatorta339@gmail.com.

Quem cuida dos seus dados

A responsável pelo tratamento dos dados (a “controladora”, na Lei Geral de Proteção de Dados — Lei nº 13.709/2018) é a La Bella Torta, na Rua Antônio Macedo, 339 – Parque São Jorge, São Paulo – SP. Para qualquer assunto de privacidade, escreva para labellatorta339@gmail.com.

Cookies

Este site não usa cookies, nem nossos nem de outras empresas, e não guarda nada no seu navegador para reconhecer você numa próxima visita. As fontes, as fotos e os scripts vêm do próprio site.

Encomendas e WhatsApp

Não existe cadastro nem formulário que envie dados para este site. Na página de encomendas, a mensagem é montada no seu próprio navegador com o que você escolhe (sabores, quantidade, data, retirada ou entrega, nome e observações). Esses dados não passam pelo site nem ficam guardados aqui: o botão apenas abre o WhatsApp no seu aparelho com o texto pronto, e você decide se envia.

Quando você manda uma mensagem para o nosso WhatsApp, usamos o que você escreveu — como nome, pedido e, se for o caso, endereço de entrega — para responder e atender o seu pedido (art. 7º, V, da LGPD). A conversa também segue a política de privacidade do WhatsApp.

Estatísticas de visita

No momento, este site não usa nenhuma ferramenta de estatísticas. Se passarmos a usar, será o Plausible Analytics, que não usa cookies e só registra números anônimos e somados — e esta página será atualizada.

Mapa do Google

Nas páginas com mapa, como a de contato, ele começa como uma ilustração. O Google Maps só é carregado se você clicar em “Carregar mapa”. A partir daí, o Google pode coletar dados de navegação, como o endereço IP, e usar cookies, conforme a política de privacidade do Google.

Hospedagem do site

O site é publicado no GitHub Pages. Como acontece em qualquer servidor, o GitHub registra o endereço IP de quem acessa as páginas, por motivo de segurança, conforme a declaração de privacidade do GitHub. Nós não temos acesso a esses registros.

Links para outros serviços

Os botões de WhatsApp, Instagram, Facebook, Google Maps e Waze levam para fora deste site. Ao abrir esses links, quem trata os seus dados é o serviço de destino, de acordo com a política de privacidade dele:

  • WhatsApp
  • Instagram
  • Facebook
  • Google Maps
  • Waze

Seus direitos

Pela LGPD (art. 18), você pode pedir a qualquer momento, sem custo:

  • a confirmação de que tratamos dados seus e o acesso a eles;
  • a correção de dados incompletos, errados ou desatualizados;
  • a anonimização, o bloqueio ou a exclusão de dados desnecessários;
  • a portabilidade dos dados e a informação sobre com quem eles foram compartilhados;
  • a exclusão de dados tratados com o seu consentimento e a revogação desse consentimento.

É só escrever para labellatorta339@gmail.com. Você também pode reclamar à Autoridade Nacional de Proteção de Dados (ANPD).

Mudanças nesta política

Se o site passar a tratar dados de outro jeito, esta página será atualizada antes, com a nova data no topo.
