# La Bella Torta — site

Site da La Bella Torta, tortaria artesanal no Parque São Jorge, Zona Leste de São Paulo.
Tortas salgadas e doces com massa fininha e recheio em dobro: na fatia, no almoço com salada ou inteiras por encomenda.

```bash
npm ci
npm run dev       # desenvolvimento em http://localhost:4321
npm run verify    # tudo que o CI roda antes de publicar
```

- **Editar conteúdo** (preços, horários, sabores, perguntas): `src/data/` — ver `docs/CONVENTIONS.md`.
- **O que falta o cliente informar**: `PENDENCIAS.md`.
- **Decisões técnicas, segurança, deploy e custos**: `ARCHITECTURE.md`.
